# 口语陪练功能实施计划书

## 一、目标

在现有学生端 App（Android Kotlin）与后端架构上，实现"AI 外教对话"完整链路：

**学生用英语说话 → ASR 转文字 → 流利度评分 → LLM 角色扮演回复并给出地道性评分 → TTS 合成语音 → 数字人形象播放**

核心指标：
- 端到端延迟 < 2s（ASR < 1s + LLM < 1s + TTS 缓存命中）
- 支持多轮连续对话（会话保持上下文）
- 零 GPU 依赖（纯 CPU 运行于 137 服务器）

---

## 二、技术选型

| 能力 | 方案 | 说明 |
|---|---|---|
| **语音识别 ASR** | sherpa-onnx（流式 WebSocket） | 基于 whisper 模型的流式封装，**开源免费（Apache 2.0）**，CPU 延迟 600-900ms；GitHub: k2-fsa/sherpa-onnx |
| **语音合成 TTS** | Coqui TTS（VITS 模型） | 英文女声，CPU 合成延迟 3-5s；通过缓存常用句压到 <1s |
| **大模型 LLM** | 复用现有 `tenant_llm.py` 网关 | 走租户 BYOM 配置，角色 Prompt 注入 |
| **数字人形象** | 静态 PNG + CSS 口型动效 | 零成本方案；说话时波形/口型闪烁，停止时恢复静态 |
| **流利度评分** | 基于 ASR 时间戳统计 | 语速（词/分钟）、停顿次数、填充词（uh/um/ah）占比 |
| **地道性评分** | LLM 判断 | Prompt 要求输出 0-100 分 + 改写建议 |


**关键决策**：sherpa-onnx 的流式识别需要 WebSocket 长连接，而 FastAPI 原生支持 WebSocket。有两种实现方式：

**方案 A**：speaking-service 直接暴露 WebSocket 端点，web-backend 通过 WebSocket 转发音频流（真流式，延迟 <1s）  
**方案 B**：speaking-service 提供 HTTP 接口，内部用 sherpa-onnx 的离线模式（每 2 秒切一段识别，伪流式，延迟 2-3s）

**MVP 阶段采用方案 B**（实现简单，快速验证功能），后续根据实测延迟决定是否升级为方案 A。

**sherpa-onnx 许可证**：Apache 2.0，完全免费可商用，无 API 费用。

#### T1.4 实现 `tts_engine.py`

```python
from TTS.api import TTS
import os

class TTSEngine:
    def __init__(self, cache_dir: str = "/app/tts_cache"):
        self.tts = TTS(model_name="tts_models/en/ljspeech/vits")
        self.cache_dir = cache_dir
        os.makedirs(cache_dir, exist_ok=True)
    
    async def synthesize(self, text: str) -> str:
        """返回音频文件路径（先查缓存，未命中再合成）"""
        cache_key = hashlib.md5(text.encode()).hexdigest()
        cache_path = os.path.join(self.cache_dir, f"{cache_key}.wav")
        
        if os.path.exists(cache_path):
            return cache_path
        
        self.tts.tts_to_file(text=text, file_path=cache_path)
        return cache_path
```

#### T1.6 实现 `main.py`（FastAPI 入口）

```python
from fastapi import FastAPI, UploadFile, File
from asr_engine import ASREngine
from tts_engine import TTSEngine
from fluency_scorer import calculate_fluency

app = FastAPI()
asr = ASREngine()
tts = TTSEngine()

@app.post("/transcribe")
async def transcribe(file: UploadFile = File(...)):
    audio_bytes = await file.read()
    result = await asr.transcribe(audio_bytes)
    fluency = calculate_fluency(result)
    return {"text": result["text"], "fluency": fluency}

@app.post("/synthesize")
async def synthesize(text: str):
    path = await tts.synthesize(text)
    return {"audio_path": path}
```

```kotlin
package com.tes.edu.util

import android.media.MediaRecorder
import android.os.Build
import java.io.File

/**
 * 录音组件：录 WAV/PCM，支持 VAD（静音自动截断）
 */
class AudioRecorder {
    private var recorder: MediaRecorder? = null
    private var outputFile: File? = null
    
    fun startRecording(outputPath: String) {
        outputFile = File(outputPath)
        recorder = if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.S) {
            MediaRecorder(context)
        } else {
            @Suppress("DEPRECATION")
            MediaRecorder()
        }.apply {
            setAudioSource(MediaRecorder.AudioSource.MIC)
            setOutputFormat(MediaRecorder.OutputFormat.WAVE)
            setAudioEncoder(MediaRecorder.AudioEncoder.PCM_16BIT)
            setOutputFile(outputFile!!.absolutePath)
            prepare()
            start()
        }
    }
    
    fun stopRecording(): ByteArray? {
        recorder?.stop()
        recorder?.release()
        recorder = null
        return outputFile?.readBytes()
    }
}
```

## 六、风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| sherpa-onnx CPU 延迟 >1s | 用户体验差 | 降级为每 2 秒分段识别；或换阿里云 ASR（按量付费 ¥0.003/秒） |
| Coqui TTS 合成慢（3-5s） | AI 回复延迟高 | 缓存常用句；预合成场景台词 |
| 并发能力弱（同时 2-3 人） | 服务卡死 | 限制单租户同时 1 个会话；横向扩容 |
| 模型文件大（~2GB） | 镜像体积大，发版慢 | 模型挂载宿主机，不打包进镜像 |
| **sherpa-onnx 流式 WebSocket 实现复杂** | **开发周期延长** | **MVP 先用离线模式（每 2 秒切段），后续再升级流式** |
| **Android 录音权限被拒** | **功能不可用** | **降级为"从相册选音频文件"或"键盘输入文字"** |
| **LLM 角色扮演跑偏** | **教学内容不准确** | **System Prompt 强约束 + 后处理过滤敏感词** |
| **TTS 缓存命中率低** | **每次都要重新合成** | **预合成高频场景台词（问候/鼓励/引导话术）** |
| **学生端网络波动（公网入口）** | **音频上传失败** | **本地先存 WAV 文件，失败后自动重试 3 次** |
| **多轮对话上下文爆炸** | **LLM token 超限/费用高** | **滑动窗口保留最近 5 轮，旧对话摘要压缩** |
| **CentOS 7 系统库版本老** | **sherpa-onnx/Coqui 编译失败** | **容器内用 python:3.10-slim，避开系统依赖** |
| **数字人静态图版权风险** | **商用侵权** | **用开源素材（Unsplash/Pexels）或自绘 SVG** |
