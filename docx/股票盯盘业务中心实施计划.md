# 股票盯盘业务中心 · 实施计划（自用版）

> 版本：v1.1 ｜ 日期：2026-11-19 ｜ 状态：自用定稿
> 目标：在 B 端管理后台顶栏「运行监控」右侧，新增第四个一级业务域「股票盯盘」，供自己内部盯盘（自选股、行情看板、涨跌预警）。
> 原则：**自己看、简单可用**：复用三段式壳子与 RBAC；免费行情源直连，不纠结对外授权；红涨绿跌。

## 一、现状分析（基于当前代码实测）

| 维度 | 现状 | 对本次的意义 |
|---|---|---|
| 顶栏一级域 | `Layout.vue` 的 `domains` = 概览域 + `CRAWL_NAV` 三个采集域（业务中心/解析审核/运行监控） | 「运行监控」右边是空位，第四个域从这里插入 |
| 导航驱动 | 采集域是纯数据配置 `web-frontend/src/utils/crawlNav.js`；主站菜单来自后端 `/menu/my` → `MENU_ROUTE_MAP` | 股票域建议走独立配置 + 后端菜单授权双轨 |
| 页面可达三要素 | ① `router/index.js` 注册路由 ② 导航配置加 `path` ③ 后端 `rbac_seed.py` 的 `MENUS`+`ROLE_MENU_MAP` 授权 | 缺任一会被 `hasRouteAccess` 弹回首页或不可见（历史踩坑） |
| 路由门禁 | `stores/auth.js` 的 `hasRouteAccess`：菜单加载后只放行 `allowedRoutes` 及其子路由 | 必须给股票菜单节点授权，否则页面打不开 |
| 网关 | `gateway/config.yaml` 前缀路由，`/api/admin/`=rbac+强制租户、`/learning/`=jwt_c | 新增 `/api/stock/` 前缀走 rbac |
| 前端依赖 | 仅 vue3 / pinia / vue-router / axios，**无任何图表库** | K 线/分时图需引入图表库 |
| 后端依赖 | fastapi / uvicorn / httpx / redis；**无 APScheduler/Celery、无行情数据源 SDK** | 定时拉行情与数据源需自建 |
| 数据层 | PostgreSQL(106) + Redis(106)，pgvector | 自选股/预警落 PG，行情快照/热点落 Redis |
| 配色 | 紫渐变顶栏 + 橙粉品牌色 + 白卡片 + 粉白底 | 盯盘页沿用设计系统，仅涨跌色用红绿 |

## 二、目标与范围

### 本期做（MVP）
1. 顶栏新增一级域「股票盯盘」，左侧二级菜单含：盯盘总览、自选股、行情看板、涨跌预警、（规划中）个股详情。
2. 自选股：增删查、分组、置顶，持久化。
3. 行情看板：指数/自选股实时（或准实时）报价列表 + 分时/K 线图。
4. 涨跌预警：用户自定义阈值，触达后在站内提示（先不做短信/微信推送）。
5. 接入 RBAC（仅 admin 可见）与租户隔离。

### 本期不做
- 不下单/交易、不接券商账户。
- 不做量化选股、回测、智能荐股。
- 实时逐笔 Level-2 行情（成本高），MVP 用延迟/快照行情。
- 微信/短信/App 推送预警（二期）。

## 三、整体设计

### 3.1 导航落位

```
顶栏： 概览 | 业务中心 | 解析审核 | 运行监控 | 【股票盯盘】  ← 新增第 4 个采集级域
                                                     └ 左侧二级：
                                                         盯盘总览 / 自选股 / 行情看板 / 涨跌预警 / 个股详情(规划)
```

新域在视觉与交互上与采集三域对齐：点顶栏 tab → 切左侧二级 → 右侧工作区渲染页面，面包屑自动显示 `首页 / 股票盯盘 / 当前页`。

### 3.2 数据流

```
行情源(新浪/腾讯/东财裸接口) ──定时拉取──> worker ──写──> Redis(最新快照) + PG(历史K线)
                                                          │
浏览器 ──3~5s 轮询──> 网关 /api/stock/ (rbac) ──> web-backend app/api/stock.py ──读──> Redis/PG
```

- **读路径**：页面 → 网关 → `stock.py` → Redis（报价）/ PG（K线、自选股、预警）。
- **写路径**：自选股/预警 CRUD → `stock.py` → PG。
- **行情更新**：独立 worker 定时拉源 → 写 Redis 快照 + PG 历史（复用采集 job 的调度思路，或 crontab + 脚本）。

## 五、技术选型（自用定法）

| 项 | 定法 | 理由 |
|---|---|---|
| 图表库 | **ECharts** | 前端无图表库；K线/分时齐全，红涨绿跌好配 |
| 行情数据源 | **新浪/腾讯/东财免费裸接口**（后端代理） | 自己看，零注册零授权，够用；失效再换同花顺扶摇或商业 API |
| 实时性 | **3–5s 轮询 + Redis 快照** | 网关 WS 未验证，轮询最稳、改动最小 |
| 定时任务 | 独立 worker 脚本 + crontab | 后端无 APScheduler/Celery，避免引入重依赖 |
| 缓存 | Redis 存最新报价，PG 存历史与业务数据 | 复用现有 106 数据层 |

## 五附：行情数据源结论（自用）

自己看，直接用**免费网页裸接口**即可，不必纠结授权：

| 源 | 用途 | 说明 |
|---|---|---|
| 新浪 `hq.sinajs.cn` / 腾讯 `qt.gtimg.cn` | 实时五档快照 | 1–3s，免费；需后端代理（浏览器直连有 Referer/跨域限制）；每秒 >10 次易封 IP |
| 东方财富 `push2.eastmoney.com` | 列表/涨幅榜/K线 | 免费、字段全；同样建议后端代理 + 限频 |
| 同花顺扶摇 `hithink-finance` | 备用/涨停池等特色数据 | 官方免费，需注册；裸接口失效时切换 |

- 只用免费源、只自己看、不对外发布/嵌入产品 → **无需采购授权**。
- 若将来要对外发布行情，才需要持牌信息商或交易所展示许可（届时另行评审）。
- 工程兜底：`Provider` 可插拔 + 本地缓存 + 字段校验 + 备用源，单一源挂了看板显示最后快照+时间戳，不拖成 500。

5. **图表库**：ECharts。

## 七、风险与注意

- **只看盘不荐股**：不加交易下单、不输出买卖建议；将来若对外发布行情再单独评审授权。
- **涨跌配色**：A 股习惯**红涨绿跌**，与欧美相反，测试中锁定。
- **导航三要素遗漏**：历史上多次因只改路由未改 `MENU_ROUTE_MAP`/`rbac_seed` 导致页面被弹回，阶段 1 必须三处齐全。
- **网关 WS**：若二期上 WebSocket 推送，需先验证网关对 WS 的转发支持，否则走 SSE/轮询。
- **数据源抖动**：Provider 超时/限流要有降级（显示最后快照 + 时间戳），不能把看板拖成 500。
- **磁盘**：137 当前约 55% 占用，新增镜像/依赖前留意空间。
