# 股票盯盘业务中心 · 实施计划（自用版）

> 版本：v1.4 ｜ 日期：2026-11-19 ｜ 状态：自用定稿
> 目标：在 B 端管理后台顶栏「运行监控」右侧，新增第四个一级业务域「股票盯盘」，供自己内部盯盘（自选股、行情看板、涨跌预警）。
> 原则：**自己看、简单可用**：复用三段式壳子与 RBAC；免费行情源直连，不纠结对外授权；红涨绿跌；预警用免费推送渠道直达微信，管理员可自主选择推自己或推指定好友。

## 一、现状分析（基于当前代码实测）

| 维度 | 现状 | 对本次的意义 |

| 数据层 | PostgreSQL(106) + Redis(106)，pgvector | 自选股/预警落 PG，行情快照/热点落 Redis |
| 配色 | 紫渐变顶栏 + 橙粉品牌色 + 白卡片 + 粉白底 | 盯盘页沿用设计系统，仅涨跌色用红绿 |

## 二、目标与范围

### 本期做（MVP）
1. 顶栏新增一级域「股票盯盘」，左侧二级菜单含：盯盘总览、自选股、行情看板、涨跌预警、推送好友、（规划中）个股详情。
2. 自选股：增删查、分组、置顶，持久化。
3. 行情看板：指数/自选股实时（或准实时）报价列表 + 分时/K 线图。
4. 涨跌预警：用户自定义阈值，触达后**站内提示 + 微信推送**（PushPlus 免费微信公众号渠道）。推送接收方支持两种：**默认推自己**（一对一），也**可指定 pushplus 好友**（好友令牌，`to` 参数，多个逗号隔开）。
5. 好友管理：维护 pushplus 好友令牌列表（别名 + 令牌），供预警选接收人。
6. 接入 RBAC（仅 admin 可见）与租户隔离。

### 本期不做
- 不下单/交易、不接券商账户。
- 不做量化选股、回测、智能荐股。
- 实时逐笔 Level-2 行情（成本高），MVP 用延迟/快照行情。
- 短信/语音/App 推送（收费或多余，本期只用微信公众号免费渠道）。

## 三、整体设计

### 3.1 导航落位

```
顶栏： 概览 | 业务中心 | 解析审核 | 运行监控 | 【股票盯盘】  ← 新增第 4 个采集级域
                                                     └ 左侧二级：
                                                         盯盘总览 / 自选股 / 行情看板 / 涨跌预警 / 推送好友 / 个股详情(规划)
```

新域在视觉与交互上与采集三域对齐：点顶栏 tab → 切左侧二级 → 右侧工作区渲染页面，面包屑自动显示 `首页 / 股票盯盘 / 当前页`。

### 3.2 数据流

```
行情源(新浪/腾讯/东财裸接口) ──定时拉取──> worker ──写──> Redis(最新快照) + PG(历史K线)
                                                          │
                          ┌── 触达阈值 ──> PushPlus /send ──┬─ 无 to ──> 推自己微信
                          │                                └─ 带 to ──> 推指定好友微信
浏览器 ──3~5s 轮询──> 网关 /api/stock/ (rbac) ──> web-backend app/api/stock.py ──读──> Redis/PG
```

- **读路径**：页面 → 网关 → `stock.py` → Redis（报价）/ PG（K线、自选股、预警）。
- **写路径**：自选股/预警/好友 CRUD → `stock.py` → PG。
- **行情更新**：独立 worker 定时拉源 → 写 Redis 快照 + PG 历史（复用采集 job 的调度思路，或 crontab + 脚本）；同时判断是否触达预警，触达则走 PushPlus：预警没配 `to` 就推自己，配了好友令牌就推给对应好友。

### 3.3 推送对象选择（管理员可控）

推送对象由管理员自己选，两级粒度，**默认推自己**：

| 层级 | 在哪选 | 规则 |
|---|---|---|
| 全局默认 | 系统设置 `stock_push_default`（新增，存 PG 或后端配置） | 选「推自己 / 推指定好友」，默认「推自己」；新建预警自动继承该默认 |
| 单条覆盖 | `views/stock/Alerts.vue` 新增/编辑预警 | 接收方：留空=推自己；勾选好友=推给对应令牌（可多选，合并一次 `to`）；优先级高于全局默认 |
| 好友来源 | `views/stock/Friends.vue` | 别名 + 好友令牌增删查；令牌来自 pushplus「我的好友」（对方扫你的好友二维码） |

- 管理员随时可改；改完对**下次触达**生效，不追溯已发消息。
- 想临时只推自己：单条预警接收方留空即可；想停掉某条推送：预警里关掉推送开关（仍落库 + 站内提示）。

## 五附：行情数据源结论（自用）

自己看，直接用**免费网页裸接口**即可，不必纠结授权：

| 源 | 用途 | 说明 |
|---|---|---|
| 新浪 `hq.sinajs.cn` / 腾讯 `qt.gtimg.cn` | 实时五档快照 | 1–3s，免费；需后端代理（浏览器直连有 Referer/跨域限制）；每秒 >10 次易封 IP |
| 东方财富 `push2.eastmoney.com` | 列表/涨幅榜/K线 | 免费、字段全；同样建议后端代理 + 限频 |
| 同花顺扶摇 `hithink-finance` | 备用/涨停池等特色数据 | 官方免费，需注册；裸接口失效时切换 |

- 只用免费源、只自己看、不对外发布/嵌入产品 → **无需采购授权**。
- 若将来要对外发布行情，才需要持牌信息商或交易所展示许可（届时另行评审）。
- 工程兜底：`Provider` 可插拔 + 本地缓存 + 字段校验 + 备用源，单一源挂了看板显示最后快照+时间戳，不拖成 500。

## 五附二：推送渠道结论（PushPlus，2026-11 官网核实）

> 来源：pushplus.plus 官网首页 / 发送渠道说明 / 会员页（2026-11 口径）。

- **免费渠道**：微信公众号（wechat，默认）、App、浏览器插件/桌面端、企业微信、钉钉、飞书、QQ 机器人、Webhook、邮件、微信 ClawBot、新消息。
- **收费渠道**：短信 10 积分/条（0.1 元）、语音 30 积分/条（0.3 元）——本期不用。
- **免费额度（实名后）**：微信 200 次/天、Webhook/插件 1000 次/天；请求频率 1 分钟 5 次；相同内容 1 小时≤3 条；消息保留 30 天。会员用积分/付费提额（微信 2000 次/天），盯盘预警用不到。
- **硬性前置**：2024-08-01 起未实名认证不能调用发送 API，须先实名。实名**收费**（一次性、终生有效），官方推荐「开 1 个月会员免费实名」最划算；用户 token + 好友令牌都要在实名账号下。
- **用法（推自己，一对一）**：`POST https://www.pushplus.plus/send`，body `{token, title, content, channel:"wechat"}`（不传 channel 默认微信）。
- **用法（推好友，好友消息）**：同上 body 再加 `"to":"好友令牌1,好友令牌2"`；好友令牌来自「我的好友」列表（添加好友是双向的，对方扫你的好友二维码）；实名用户单次 `to` 最多 10 个、最多加 1000 好友；`webhook` 渠道不支持好友消息。好友≠微信通讯录好友，须是 pushplus 用户。
- **安全**：token 是发送凭证，只放后端环境变量 `PUSHPLUS_TOKEN`，不进 git、不写库、不打日志；好友令牌落库但属敏感配置，不进日志。
- **发送是异步的**：接口同步返回「请求成功」不等于真送达，按返回码判断、必要时用流水号查结果，避免异常时反复重发导致封号。

## 七、风险与注意

- **只看盘不荐股**：不加交易下单、不输出买卖建议；将来若对外发布行情再单独评审授权。
- **涨跌配色**：A 股习惯**红涨绿跌**，与欧美相反，测试中锁定。
- **导航三要素遗漏**：历史上多次因只改路由未改 `MENU_ROUTE_MAP`/`rbac_seed` 导致页面被弹回，阶段 1 必须三处齐全。
- **网关 WS**：若二期上 WebSocket 推送，需先验证网关对 WS 的转发支持，否则走 SSE/轮询。
- **数据源抖动**：Provider 超时/限流要有降级（显示最后快照 + 时间戳），不能把看板拖成 500。
- **推送 token 安全**：`PUSHPLUS_TOKEN` 只进后端环境变量，不入库不进日志；好友令牌落库但不打日志；推送失败不能拖垮 worker（捕获异常 + 降级站内提示）。
- **推送限频**：同名内容 1h≤3 条、1 分钟≤5 次；预警要有冷却去重，别让同一条阈值反复刷屏导致账号被限。推多个好友时合并为一次 `to`（逗号隔开）而非逐个请求，省次数、防限频。
- **好友消息边界**：webhook 渠道不支持好友消息，走微信公众号渠道；单次 `to` 实名≤10 人，超出被静默截取，前端要提示上限。
- **磁盘**：137 当前约 55% 占用，新增镜像/依赖前留意空间。
