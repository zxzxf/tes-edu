## 一、P1 内容扩量（T-A1 ~ T-A4）

> 目标：把 `course_kb` 从 213 题扩到 ≥3000 题（含解答题/压轴题），让 RAG 有东西可检、自适应有题可推。
> 来源策略（沿用分期计划书 R2）：a) 新高考 I 卷 11 省真题（已部分入库）；b) **人教 A 版教材例题/习题（主要缺口）**；c) 教研自产/采购。

### T-A1 素材加工流水线固化（0.5 天）
- **目标**：把"真题/教材/采购题 → import_bank 可直接吃的格式"做成可重复、可审计的管线，消除每次手工转格式的静默坑。
- **关键任务与落点**：
  - 复用 `真题素材/export_for_import.py`（已规避 import_bank 三坑：题型中文映射 / 知识点存 DAG id 不被 `/` 切碎 / source_province 截断），补一个 `--from-textbook` 开关加工**人教 A 版教材题**源（解析教材 PDF/Word 的例题与习题，标注章节→对应 `kb_knowledge_points.code`）。
  - 复用 `真题素材/build_steps.py`（全题型步骤分解器：单选/多选按选项、填空按空、解答按 sub_questions/解析拆步、兜底 single 步）保证每题 ≥1 步。
  - 产出统一中间格式（参照 `bank_数学_2021-2026_细标.json` 的 16 字段），落 `真题素材/bank_*.json`。
- **验收**：对任意新来源跑 `export_for_import.py` 一次产出中间 JSON；`python import_bank.py <file> --dry-run` 列数映射 100% 命中、sample 预览字段正确；错题/缺字段有清晰报错而非静默 None。

## 二、AGE / P3 图谱启动（T-B1 ~ T-B5）

> 核心发现：**知识点 DAG 已用关系表（`kb_knowledge_points` + `kb_kp_prerequisites`）实现并灌库，并未使用 Apache AGE**。
> 因此"图谱初始化"实质已完成，缺的是 **P3 算法层**（掌握度更新 / ZPD / 推题）与 **App 可视化**，以及 P0 DoD 的形式化验收。
> AGE 是否真要部署，作为**可选升级项（T-B4）**，不阻塞 P3。

### T-B1 DAG 验收固化 + 边细化（0.5 天）
- **目标**：把现有关系表 DAG 作为 P0 DoD「图谱初始化」的等效验收落地，并补细粒度前置边。
- **关键任务与落点**：
  - 复用 `import_knowledge_dag.py` 已有的**无环校验 + 拓扑排序覆盖 100%** 作为验收脚本（`python import_knowledge_dag.py --check-only` 或抽成 `scripts/verify_dag.py`）。
  - 当前 435 边为层级链（每点约 1 前驱）。教研补**知识点级前置**（如"二次函数"→"韦达定理"），把边从 435 增到真正的 DAG 密度；新增边走同一 `kb_kp_prerequisites` 表、幂等。
- **验收**：拓扑排序覆盖 100%、无悬空引用；知识点级前置边 ≥800；`kb_knowledge_points` 含 core 标记（高频考点）。

### T-B2 掌握度更新算法（1.5 天）
- **目标**：学生做题后更新掌握度向量，支持解答题**按步骤拆分到多个知识点**（衔接 S3 judge_v2 的 first_wrong_step/error_type）。
- **关键任务与落点**：
  - 新增 `web-backend/app/services/mastery.py`：`update_mastery(db, student_id, content_hash, step_results)`。
  - 答对 → 正向更新（该点 + 祖先节点沿 `kb_kp_prerequisites` 递归上溢）；答错 → 负向 + 沿 DAG **回溯前置薄弱点**（递归 CTE）。
  - 遗忘衰减：长期未练按艾宾浩斯衰减（定时任务或读取时衰减）。
  - 步骤→知识点映射取 `course_kb_steps.kp`（已有），多步错则多知识点加权。
  - 落 `student_mastery` 表（已存在）。
- **验收**：单测覆盖 答对/答错/部分步错/遗忘衰减四种；祖先上溢与前置回溯方向正确（用 435 点 DAG 构造小样例断言）；与 S3 事件流（`student_step_errors`）接通：错一步只扣该步知识点，不污染已掌握的祖先。

### T-B3 ZPD 计算 + 自适应推题引擎（2 天）✅ 已完成（2026-10-24）
- **目标**：基于掌握度图谱算最近发展区，只推 ZPD 内题；难度自适应 + 变式推荐。
- **关键任务与落点**：
  - `web-backend/app/services/adaptive.py`：`compute_zpd(db, student_id)` 用递归 CTE 沿 DAG 求"前置已掌握、当前未掌握"区间；`recommend(db, student_id, n)` 调 T-A4 组卷接口取 ZPD 内、难度自适应题。
  - 错题闭环：定位薄弱点 → 推变式 → 生成间隔重复计划（复用 `student_mastery` + 衰减）。
  - 多学生并发安全：连接池 + 事务。
- **验收**：推题 100% 落在 ZPD（单测构造掌握度断言不推已掌握点）；难度随答对升/答错降；与 S5 周报"薄弱点"数据同源。
- **完成情况**：
  - 新增 `app/services/adaptive.py`（纯函数 + DB 薄层，复用 T-B2 `walk_up`/衰减）：
    - `compute_zpd`：前置就绪（有记录且<0.8 才阻塞；缺省按就绪，同 T-B2 约定）+ 自身未掌握；
      冷启动根节点全就绪，形成学习路径起点。
    - `depth_map`：最长前置链深度，ZPD 排序=薄弱点优先 + 浅的先学。
    - `difficulty_band`：easy/medium/hard，近期正确率与掌握度各半权重（答对升档、答错降档）。
    - `plan_review`：间隔重复计划，"曾掌握、正在遗忘"按紧迫度（days_until_review）升序，
      未真掌握/还很熟/只练没判分均不排入。
    - `recommend`：ZPD 内 weakest-first 选课，每题带 target_kp/band/掌握度（可解释）；
      附复习计划。选课查询与 T-A4 共用（T-A4 落地后可委托）。
  - API：`GET /learning/recommendations`（ADMIN/TEACHER/PARENT/STUDENT，n=1~20）。
  - 单测 `tests/test_adaptive.py` **18 例**：100% 落 ZPD（已掌握绝不入）/ 薄弱前置阻塞 /
    缺省就绪 / 冷启动 / 难度升降档 / 复习三态与排序 / 深度排序 / 环防御；
    web-backend 全量 **109 passed**（原 91）。
  - 106 真实库只读冒烟：435 节点、冷启动 ZPD=435、数学推荐 5 题全部带 target_kp 与难度带落地。
  - **已知数据缺口（内容线，非代码）**：`kb_knowledge_points` 仅数学 435 节点；物理 90 题
    知识点标签为中文模块名（力学/电磁学…）未挂 DAG code → 物理 ZPD 为空、暂不能推题，
    待物理知识点图谱补齐（归 T-A2 扩量线）。
  - **踩坑**：SQLAlchemy `text()` 中「绑定参数后接 `::`」（如 `:s::text`）会破坏参数解析
    （asyncpg 报 syntax error at ":"）；列上的 `::jsonb` 安全。已改用条件式 subject 变体 +
    `jsonb_array_elements_text(...) = :kp` 标量等值，彻底避开。

### T-B4 AGE 部署决策（可选，不阻塞 P3，0.5 天评估 + 如需则 1–2 天）
- **目标**：回答"是否真要引入 Apache AGE"，给出可执行决策。
- **方案对比**：
  - **方案 A（推荐，固化关系表）**：不引 AGE，用 `kb_knowledge_points` + `kb_kp_prerequisites` + 递归 CTE 支撑 T-B2/T-B3。300 节点 DAG 递归 SQL 毫秒级，**零新增运维风险**，本周可全跑通 P3。
  - **方案 B（真部署 AGE）**：在 106 PG16 上加 `age` 扩展（需评估 AGE 1.5.x 与 PG16 兼容、容器内编译/安装、现有数据迁移到图标签的风险）。收益在当前规模可忽略，仅在"图谱膨胀到万级节点 + 高频图遍历"时才显著。
- **决策落点**：默认走方案 A，把 T-B1 的无环校验作为 P0 DoD 等效验收；方案 B 仅在后续真实数据量证明递归 CTE 成为瓶颈时启动（届时单独立项，不阻塞当前 P3）。

### T-B5 App 知识图谱可视化页（1 天）

- **关键任务与落点**：`student-app` 新增"图谱"页（Jetpack Compose），调 `web-backend` 掌握度接口（T-B2/T-B3 产出）；前端 DAG 渲染（可复用现有图表库，节点着色按掌握度）。
- **验收**：展示个人知识点掌握度热力；点击薄弱点能跳转对应变式题（接 T-B3）。
