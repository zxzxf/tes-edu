开发顺序： ① 先后端（P0 Agent 后端 + Go 网关 + RBAC）→ ② 后双端（P1 App 补全、P2 Web 学情/错题）→ ③ 再补可选跨端（P3 教务模块 + 小程序）。
技术栈： Go 网关 + Python 双后端(Agent/Web, FastAPI) + Kotlin 安卓 + Vue3 管理前端 + Kafka/PostgreSQL(向量/AGE)。 核心原则： 一套内核、多端复用——学生 App 与 Web 后台都只经 Go 网关，再分流到各自后端，不重复造轮子；私有化部署是相对巨头的核心差异化优势。
