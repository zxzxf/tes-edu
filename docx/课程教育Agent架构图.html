网关层路由：/api/app/*、/solve、/solve_image → Agent 后端(Python)；/api/admin/* → Web 后端服务(Python)；文件上传先到网关再转交。
语言分工：网关 Go（边缘高并发、单二进制）；Agent 与 Web 后端均 Python/FastAPI（同栈复用、仅 2 种服务端运行时）；安卓 Kotlin。
关键设计：网关为唯一公网入口，后端不直接暴露；鉴权/限流/审计日志在网关层统一落盘，直接承接合规缺失项 #8；私有化部署、数据不出域。
替代选型：不想引入 Go 可用 APISIX/Kong（配置为主）；团队 Java 为主可换 Spring Cloud Gateway 复用 aas-api 的 Spring 安全体系。
