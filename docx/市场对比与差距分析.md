# Tes Edu 市场对比与差距分析

> 编写日期：2026-10-21
> 数据来源：《课程教育 Agent 设计方案.md》第六节（市场对比）、本次任务方案评审、《计划 vs 现状差距报告.md》
> 结论先行：**方案差异化定位清晰（图谱驱动×苏格拉底×私有化），但目前是"纸面优势"——AI 能力全为占位，且合规/题库版权/标注产能/效果量化四类前置硬门槛只在方向上覆盖、未在预算与责任上落点。**

## 一、相对市场缺少什么

> 前提：差距报告已确认服务器跑的是 mock 桩，RAG/OCR/VLM/编排均为占位。因此"缺少"分两层——相对成熟竞品真实能力的差距，以及计划本身未覆盖的项。

| 能力维度 | 成熟竞品（作业帮/小猿/学而思/有道/可汗） | 本方案现状 / 缺口 |
|---|---|---|
| 拍照搜题 + 题库体量 | 海量正版题、OCR 极强、版面切题/多题识别成熟 | 起步弱，需自建 OCR+题库；多模态拍照、版面切题、多题识别均未做 |
| 手写 / 公式识别 | 较强 | 需补手写 OCR + 公式 LaTeX 还原（计划 P3） |
| 视频 / 直播 / AI 老师形象 | 强（学而思、有道重投入） | 缺失，标为"低优先级、成本高" |
| 家校 / 教师端 | 有完整闭环 | 仅设计到 RBAC 框架，教师批改、家校互通实质缺失 |
| 评测闭环 | 有自动组卷、周测、薄弱点诊断 | 需补自动组卷、薄弱点诊断（错题本已在设计） |
| 实时语音交互 | 部分已有 | 放 P4，尚未覆盖 |
| 合规与教育 App 备案 | 已备案成熟 | **必须补**——差距报告判 🔴 严重（当前仅路由桩） |

### 易被忽视、但决定生死的缺项（方向已给、落点未定）

- **正版题库与版权**：竞品核心护城河是多年沉淀的正版题库。本方案走"轻量/私有化避开硬碰"路线，但首期 3000 题从何而来、版权是否干净，计划书只给了来源策略（外省真题 + 人教 A 版教材 + 采购），**未落实采购/授权机制**。
- **真实标注成本**：一题带"知识点+难度+卷别"标注的人工极贵。计划书用 DoD（≥3000 题、100% 标注）兜底，但**未算标注产能与预算**。
- **留存与效果验证**：自适应路径声称"练习量降、掌握度升"，计划书只写"内测≥10 人"，**未定义统计显著性**，易被质疑。

## 二、相对市场的优势（方案押注的差异化）

| 优势 | 说明 | 市场参照 |
|---|---|---|
| **图谱驱动 × 自适应路径** | 知识点 DAG + 掌握度向量 + 最近发展区(ZPD)，推题落在"已掌握前置、未掌握当前"区间 | 多数竞品是**题库驱动**（题→题推荐），图谱驱动少见，是真正的差异化点 |
| **苏格拉底引导式** | `/solve` 默认不直接给答案，反问→渐进提示→最后才讲；与市场头部(Khanmigo/小励/上清北)对齐的教学底线 | 通用大模型(豆包/ChatGPT)**无学情闭环、易幻觉、不适合直接应试** |
| **轻量 + 可私有化** | 学校/机构本地部署、数据不出域，Go 网关单二进制 + 合规在网关统一落盘 | 巨头重运营、依赖真人师资、边际成本高；本方案合规友好，避开正版题库硬碰 |
| **灵活讲解 × 应试准确** | LLM 个性化分步讲解 + 自建 K12 知识库(pgvector+AGE)防幻觉 | 通用模型易幻觉；模板化讲解缺个性 |
| **战略聚焦：河南·高中·数学·新高考 I 卷** | 数学是全国 I 卷统一命题，一套内容可复用到 11 个新高考 I 卷省份；选考科目则河南自主命题（复用率=1） | 多数竞品广撒网、缺乏可复制的区域打法 |
| **自研 Go 网关统一底座** | 鉴权/限流/审计/合规在网关层统一，已落地骨架 | — |

## 三、一句话结论

**优势是真实的、且定位清晰**：图谱驱动自适应 + 苏格拉底 + 私有化，这三点组合在"学校/机构本地部署"细分市场有差异化空间，不是和巨头正面拼题库。

**但当前是"纸面优势"**：差距报告已确认 AI 能力全为占位，且缺少项中**合规备案、正版题库来源、标注产能、效果量化验证**四项是上线/获客的前置硬门槛，计划书给了方向但没给预算与责任落点。

**建议（P0 即立项）**：
1. 把"题库版权合规与授权机制"在 P0 立项，明确首期 3000 题的合法来源与采购预算。
2. 把"内测效果量化方案"前置定义（样本量、对照设计、显著性标准），避免 P3 末才发现问题。
3. 标注产能与成本单独排期，与 P1 内容地基并行，防止题库灌入被标注卡住。
