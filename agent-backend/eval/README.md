# 金标准模板说明（S6 评测用）

试点数据到位后，由两位教师**背靠背**填写本模板，每行对应「一个学生对一道题的一次作答」。

## 字段定义（无歧义约定）

| 列名 | 定义 | 示例 |
|---|---|---|
| `content_hash` | 题目在 `course_kb` 中的唯一标识（判分时按它取参考步骤，**必填**） | `a1b2c3...` |
| `题型` | 单选/多选/填空/解答（决定走查表还是 LLM 判分路线） | 解答 |
| `step_no` | 该作答对应参考步骤的步骤号（定位到 `course_kb_steps` 哪一步；整题级填 1） | 3 |
| `学生作答过程` | 学生提交的原始过程文本（解答题须 ≥12 字，否则判分器要求补过程、不计入指标） | "f'(x)=1-lnx+x*(-1/x)=..." |
| `金标准首错步骤` | 教师判定学生**第一个出错**的参考步骤号；**全对留空** | 1 |
| `金标准错因` | 错因七类**英文码**（judge v2 taxonomy 同款）：`concept` 概念理解 / `formula` 公式误用 / `case` 分类讨论遗漏 / `calc` 计算运算 / `read` 审题漏条件 / `logic` 逻辑跳步 / `strategy` 方法策略；全对留空 | calc |
| `评分人A` / `评分人B` | 两位教师独立标注的错因码（互不商量） | calc |
| `仲裁结果` | 两人不一致时，由第三人仲裁填最终错因码；一致时留空 | logic |

## 填写要点

1. **首错步骤**只看"第一个错"，后面的错不连坐；
2. **全对**的行：`金标准首错步骤`/`金标准错因`/`评分人A`/`评分人B` 全部留空（脚本按" judge 返回 None 即对齐"计分）；
3. 错因码**只填英文码**（与 judge v2 输出口径一致，避免中文归一化歧义）；
4. 一行一个 (学生, 题) 组合；同一学生多次作答同一题请分行。

## 使用

```bash
# 教师填好 gold_standard.csv 后：
python scripts/eval_attribution.py --gold eval/gold_standard.csv --batch 2026-试点校-批次1
# 结果归档到 eval/2026-试点校-批次1/（原始金标准副本 + report.md + results.json）
```

指标口径（与《归因线收尾与验收任务计划》T4 一致）：
- 客观题查表命中率（`attribution_source=map` 占比，应 ~100%，零 token）
- 解答题首错步骤对齐准确率（要求 ≥85%）
- 错因分类准确率 + unknown 率（unknown 要求 ≤10%）
- 评分人 A/B 的 Cohen's κ（标注质量自检）
